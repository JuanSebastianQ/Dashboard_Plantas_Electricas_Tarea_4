# Dashboard de la Plantas Electricas para la Tarea 4

## Descripción del proyecto

Este proyecto consiste en realizar un análisis exploratorio de datos (EDA) sobre la infraestructura de generación eléctrica a nivel mundial, con el propósito de identificar patrones, tendencias y diferencias en la producción de energía según el tipo de combustible, la ubicación geográfica y la capacidad de las plantas. Se busca comprender cómo está distribuida la infraestructura energética, cómo ha evolucionado a través del tiempo y qué relación existe entre la capacidad instalada y la generación estimada de electricidad.
